# Public Certificates (FreeTSA)

This directory contains public X.509 certificates provided by [FreeTSA](https://freetsa.org/). They are required for the **offline verification** of RFC 3161 TimeStampTokens (`.tsr` files) generated by AstroProv.

## Files

- `cacert.pem`: The FreeTSA Root CA certificate. It acts as the Trust Anchor.
- `tsa.crt`: The FreeTSA Time Stamping Authority (TSA) responder certificate. It is used to verify the signature on the timestamp token.

## Why are they in the repository?

Bundling these certificates ensures **long-term validation**. Even if the FreeTSA service goes offline, changes its certificates in the future, or the user has no internet access, AstroProv can still cryptographically prove that a `.tsr` file was validly signed by FreeTSA at the time of sealing.
